## D2：结构化输出用「预算阶梯 + 解析失败安全降级」，不引入 function calling / JSON mode 强约束

- **决定：** router、planner、sufficiency、rewrite 全部走"首轮 budget → 空输出带收尾提示逐级升预算（1024→2048→4096）→ 解析失败降级为安全值（single / sufficient=true）"。
- **理由：** 主模型 deepseek-v4.1-flash 带思维链，预算 512 时约 27% 的题推理链吃光预算出空答案（`runs/diag/`）；实测阶梯能救回，而强约束输出格式对"推理吃预算"无效。
- **代价：** 单题 LLM 调用数不稳定、成本方差大；解析层是手写正则而非 schema 校验（阶段 1 要补 Pydantic，但不得删掉这两个机制）。
