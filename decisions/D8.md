## D8 · 控制流统一走 graph runner（`use_graph` 默认 True，保留顺序实现作对照）

- **决定：** `AgentConfig.use_graph` 默认 `True`；`Agent.answer` 在默认路径上委托给 `GraphRunner`，`use_graph=False` 走旧的 `_answer_sequential`。`scripts/eval_qa.py` 增加 `--no-graph` 用于复现历史行。
- **实现边界：** core → graph 用**方法内延迟导入**避免循环依赖；LangGraph 状态里只放"下一步走哪条边"，业务事实仍在 `AgentState`/`AnswerTrace`。
- **依据：** 11 条对照测试（含 direct / scripted / rewrite / 早停 / 轮数预算 / 拒答 / 核验修复 / 修复用尽），在 answer/evidence/rounds/queries/n_llm_calls/n_calls/stop_reason/tokens 上逐项一致；另有 1 条在 `Agent` 公开 API 层对比 `use_graph` 开/关。
- **口径提示：** 本轮六配置基线是在 `use_graph` 尚未接线时跑的（顺序实现）。由于两条路径等价，表格可与后续 graph 跑数直接对比；但 manifest 里早期行没有 `use_graph` 字段，复现时以 `--no-graph` 对齐。
